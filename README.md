# Zombie Horde — NeoForge 1.21.1

Готовый исходный проект мода для **Minecraft 1.21.1 + NeoForge 21.1.251**.

## Что делает мод

- Раз в **60 секунд** для каждого активного игрока появляется орда рядом с ним.
- В творческом режиме волны по умолчанию отключены; наблюдатели всегда пропускаются.
- Каждая 5-я волна получает +2 моба и повышенный шанс громил.
- Новые типы мобов с собственными моделями, текстурами и анимацией:
  - **Зомби-бегун** — быстрый, накладывает голод, оставляет облачные частицы.
  - **Зомби-громила** — много здоровья/брони, замедляет при ударе, дымится.
  - **Чумной зомби** — яд + голод, споровые частицы.
  - **Огненный зомби** — поджигает и накладывает слабость, огненные частицы.
- Все ордовые зомби не горят от солнца и не превращаются в утопленников.
- При убийстве ордового зомби игроком выдаётся **мешочек с наградой** (по умолчанию 100%).
- ПКМ по мешочку даёт случайный набор ресурсов, опыт и один временный бафф.
- При старте волны: сообщение в action bar, звук, дым, краткая тьма для атмосферы.

## Сборка

Нужна **Java 21**.

Linux/macOS:

```bash
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

Готовый JAR появится в `build/libs/`.

> В этом архиве лежит маленький совместимый bootstrap `gradle-wrapper.jar`. При первом запуске он читает `gradle-wrapper.properties`, скачивает официальный Gradle 9.2.1 и затем запускает обычную сборку. Это сделано только потому, что стандартный бинарный wrapper JAR нельзя было получить в среде генерации проекта.

## Запуск из среды разработки

```bash
./gradlew runClient
```

Для тестового сервера:

```bash
./gradlew runServer
```

## Конфиг

После первого запуска создаётся common-конфиг NeoForge. В нём можно менять:

- `waveIntervalSeconds` — интервал волн, по умолчанию 60;
- `minHordeSize` / `maxHordeSize` — размер волны;
- `minSpawnRadius` / `maxSpawnRadius` — радиус появления;
- `spawnForCreativePlayers` — атаковать ли игроков в creative;
- `rewardBagChancePercent` — шанс мешочка за убийство.

## Основные файлы

- `HordeEvents.java` — таймер, волны, спавн и награда за убийство.
- `HordeZombie.java` + 4 класса мобов — поведение и эффекты.
- `client/model` и `client/renderer` — кастомные модели, текстуры и анимации зомби.
- `RewardBagItem.java` — таблица наград, опыт, баффы.
- `HordeConfig.java` — настройки.
- `ModEntities.java` / `ModItems.java` — регистрации NeoForge.

## Примечание по проверке

Проект сформирован по структуре официального NeoForge MDK для 1.21.1 (Java 21, ModDevGradle 2.0.147, NeoForge 21.1.251). В среде генерации не было сетевого доступа из build-контейнера, поэтому зависимости Minecraft/NeoForge невозможно было скачать и выполнить полный `gradlew build`; исходники и локальные файлы проекта проверены статически, а bootstrap-wrapper скомпилирован отдельно.
